# Σύνθεση Η/Υ Διαχειρηστή

**Πρωτεύων Actor:** Διαχειριστής

**Ενδιαφερόμενοι:**
Διαχειριστής: θέλει να δημουργήσει υπολογιστή για τις έτοιμες προτεινόμενες συνθέσεις.

## Βασική Ροή
_Κληρονομεί την ΠΧ ['Σύνθεση Η/Υ'](uc_build.md)_

## Α) Δημιουργία Σύνθεσης

1. Μέλος της ομάδας διαχείρησης εκτελεί [Σύνθεση Η/Υ](uc_build.md) (βήματα 1-7 της βασικής ροής) και δημιουργεί ένα Build (συγκεκριμένα Admin_Build).
2. Με την ολοκλήρωση μπορεί να ορίσει νέα τιμή τον υπολογιστή που δημιούργησε (discount price).
3. Μπορεί να προσθέσει τον Υπολογιστή στην λίστα των προτεινόμενων συνθέσεων.

### Εναλλακτικές Ροές

1α. _Η σύθεση ακυρώνεται._

- Η περίπτωση χρήσης τερματίζει.
