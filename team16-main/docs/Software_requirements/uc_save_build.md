# ΠΧ Αποθήκευση σύνθεσης Η/Υ

**Πρωτεύων Actor:** Πελάτης\
**Ενδιαφερόμενοι:**\
**Πελάτης:** Επιθυμεί να αποθηκεύσει μια σύνθεση Η/Υ στη προσωπική του λίστα, την οποία Θα την έχει δημιουργήσει ο ίδιος και μπορεί να είναι ολοκληρωμένη, μπορεί όμως να βρίσκεται και σε κάποιο αρχικό στάδιο και να λείπουν κάποια εξαρτήματά της (την αποθηκεύει δηλαδή για να τη συνεχίσει αργότερα ενδεχομένως).

**Προϋποθέσεις:** Να υπάρχει κάποια έτοιμη/σε εξέλιξη σύνθεση, η οποία να μπορεί να αποθηκευτεί.

## Βασική Ροή
_Extends: [Σύνθεση Η/Υ πελάτη](uc_customer_build.md) στο EP1: SaveBuild_

## A) Αποθήκευση Σύνθεσης

1. Ο πελάτης επιλέγει τη σύνθεση που επιθυμεί να αποθηκεύσει.
2. Το σύστημα ελέγχει ότι όλα τα εξαρτήματα από τα οποία απαρτίζεται η σύνθεση είναι συμβατά μεταξύ τους.
3. Η σύνθεση αποθηκεύεται σε ειδική λίστα με όλες τις αποθηκευμένες συνθέσεις του πελάτη, τις οποίες θα μπορεί να τροποποιήσει/ολοκληρώσει οποιαδήποτε στιγμή.

### Εναλλακτικές Ροές

2.α _Δεν ικανοποιούνται οι συνθήκες συμβατότητας._

- Η σύνθεση δεν μπορεί να αποθηκευτεί.

## Β) Διαγραφή Αποθηκευμένης Σύνθεσης

1. Εφόσον την αποθηκεύσει στη προσωπική του λίστα, ο πελάτης επιθυμεί να αφαιρέσει τη σύνθεση αυτή.
2. Η σύνθεση διαγράφεται από τη προσωπική του λίστα και δεν θα είναι πλέον προσβάσιμη.

## Γ) Πρόσβαση σε αποθηκευμένη σύνθεση

1. Ο πελάτης ανατρέχει στη λίστα με τις αποθηκευμένες συνθέσεις του.
2. Επιλεγει τη σύνθεση που επιθυμεί να τροποποιήσει.
3. Το σύστημα κατευθύνει τον πελάτη στο περιβάλλον της "Σύνθεσης Η/Υ" με τα επιλεγμένα εξαρτήματα τοποθετημένα. Κάνει όποιες αλλαγές επιθυμεί και την επαναποθηκεύει.

### Εναλλακτικές Ροές

3.α _Τα εξαρτήματα της τροποποιημένης σύνθεσης δεν πληρούν τα κριτήρια συμβατότητας_

- Εμφανίζεται κατάλληλο μήνυμα σφάλματος και δίνεται η επιλογή στον πελάτη να συνεχίσει τη τροποποίηση/να επιστρέψει στην αρχική μορφή της σύνθεσης πριν τις όποιες αλλαγές
