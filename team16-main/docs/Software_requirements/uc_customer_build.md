# Σύνθεση Η/Υ Πελάτη

**Πρωτεύων Actor:** Πελάτης

**Ενδιαφερόμενοι:**
Ο πελάτης επιθυμεί να ξεκινήσει την σύνθεση του Η/Υ.

## Βασική Ροή

_Κληρονομεί την ΠΧ ['Σύνθεση Η/Υ'](uc_build.md)_

## Α) Δημιουργία Νέας Σύνθεσης

1. Ο πελάτης επιλέγει να ξεκινήσει την δημιουργία νέας σύνθεσης.
2. Εκτελείται η ["Σύνθεση Η/Υ"](uc_build.md) (βήματα 1-7 της βασικής ροής). Αποτέλεσμα είναι η δημιουργία ενός Build (συγκεκριμένα Customer Build).
3. Με την ολοκλήρωση ο πελάτης βλέπει τον ολοκληρωμένο υπολογιστή και την τελική τιμή.\
   Extention Points
   - EP1: [SaveBuild](uc_save_build.md)
   - EP2: [PublishBuild](uc_publish_build.md)
4. Μπορεί να επιλέξει να αγοράσει την σύνθεση που δημιούργησε, περιλαμβάνεται (include) η ΠΧ ["Αγορά Η/Υ](uc_order.md).

### Εναλλακτικές Ροές

2α. _Να ακυρωθεί η δημιουργία της σύνθεσης._

- Η περίπτωση χρήσης τερματίζει.
