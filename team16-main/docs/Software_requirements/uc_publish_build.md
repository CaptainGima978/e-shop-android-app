# ΠΧ Δημοσίευση σύνθεσης Η/Υ

**Πρωτεύων Actor:** Πελάτης\
**Ενδιαφερόμενοι:**\
**Πελάτης:** Δημοσιεύει μια σύνθεση Η/Υ την οποία ο ίδιος συναρμολόγησε, προκειμένου να την δουν άλλοι χρήστες της εφαρμογής και να την αξιολογήσουν/ να εμπνευστούν από αυτή για τις δικές τους συνθέσεις.\
**Χρήστης(άλλοι χρήστες):** Αξιολογούν τη δημοσιευμένη σύνθεση ή ακόμα και τη χρησιμοποιούν για να πάρουν ιδέες.\
**Διαχειριστής:** Αξιολογεί και αυτός με τη σειρά του τη δημοσιευμένη σύνθεση και αν είναι πραγματικά καλή, την προσθέτει στον κατάλογο των έτοιμων συνθέσεων κατόπιν συννενόησης με τον δημιουργό της.

**Προϋποθέσεις:** Ο πελάτης να έχει πραγματοποιήσει σύνθεση Η/Υ προκειμένου να έχει τη δυνατότητα να τη δημοσιεύσει.

## Βασική Ροή
_Extends: [Σύνθεση Η/Υ πελάτη](uc_customer_build.md) στο EP2: PublishBuild_

### Δημοσίευση σύνθεσης Η/Υ

1. Μετά την επιτυχή [σύνθεση του Η/Υ του](uc_customer_build.md),
2. Ο πελάτης επιλέγει να τη δημοσιεύσει

## Εναλλακτικές Ροές

2α. _Εφόσον ο πελάτης δημοσιεύσει τη σύνθεσή του, για κάποιο λόγο επιθυμεί να την αφαιρέσει._

- Η σύνθεση θα καταργείται από τις δημοσιευμένες και δεν θα είναι πλέον προσβάσιμη για αξιολόγηση
